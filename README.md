# 🎓 WAEC Pass Likelihood Prediction System

## 📌 Project Overview

The **WAEC Pass Likelihood Prediction System** is a machine learning-based web application designed to predict students' likelihood of passing the West African Examinations Council (WAEC) examination.

The system evaluates students' academic performance indicators, including study habits, class attendance, and mock examination scores, to generate predictive insights into their examination performance.

It is designed to help students identify areas that require improvement and encourage better academic preparation.

## 🎯 Project Objectives

- Predict students' likelihood of passing the WAEC examination using machine learning.
- Assess the influence of study habits on academic performance.
- Evaluate the relationship between attendance and examination success.
- Use mock examination scores as an indicator of academic readiness.
- Provide useful insights to support students' academic improvement.

## ⚙️ Technologies Used

- **Python** – Programming language.
- **Streamlit** – Interactive web application framework.
- **Scikit-learn** – Machine learning model development.
- **Pandas** – Data manipulation and analysis.
- **NumPy** – Numerical computations.
- **Joblib/Pickle** – Model storage and loading.

## 💻 Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/waec-pass-prediction-system.git
```

### 2. Navigate to the project directory

```bash
cd waec-pass-prediction-system
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

## 🌐 Deployment

## ⚠️ Disclaimer

This application provides estimated predictions based on the information supplied and the trained machine learning model. Predictions are not guarantees of actual WAEC examination results and should not replace proper academic preparation or official examination results.
